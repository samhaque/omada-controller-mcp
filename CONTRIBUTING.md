# Contributing

## Setup

```bash
uv sync
uv run omada-mcp
```

No `OMADA_CLIENT_ID`/`OMADA_CLIENT_SECRET` reachable? The server falls back to the bundled
`openapi/controller-spec.json` snapshot, that's expected, not a bug.

## Tests

Plain `assert` scripts, pytest-discovered:

```bash
uv run pytest
```

Add new tests as `test_*.py` functions following this pattern.

## Style

```bash
uv run ruff check .
uv run ruff format .
```

## `src/omada_client`

Machine-generated by `openapi-python-client`. Never hand-edit it. To pick up a spec change:

```bash
./scripts/regenerate.sh
```

## Changelog

User-facing changes get an entry in `CHANGELOG.md` (Keep a Changelog format, semver tags).
